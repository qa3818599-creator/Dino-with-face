# Dino with face

เกมวิ่งหลบสิ่งกีดขวางสไตล์ Chrome Dino ควบคุมได้ด้วยคีย์บอร์ดและกล้อง โดยเปิดปากเพื่อกระโดด และก้มหน้าเพื่อหมอบหลบ

## ฟีเจอร์

- กระโดดข้ามกระบองเพชร
- หมอบหลบ Pterodactyl
- ควบคุมด้วยคีย์บอร์ดหรือการตรวจจับใบหน้า
- ความเร็วเพิ่มขึ้นตามคะแนน
- บันทึกคะแนนสูงสุดไว้ในเบราว์เซอร์
- มีหน้า Settings, Scoreboard และ How to play

## วิธีเปิดเกม

โปรเจกต์นี้ไม่ต้องใช้ Python และไม่มีขั้นตอน build

1. ติดตั้งส่วนขยาย **Live Server** ใน VS Code
2. เปิดโฟลเดอร์โปรเจกต์นี้ใน VS Code
3. คลิกขวาที่ `web/index.html`
4. เลือก **Open with Live Server**
5. เกมจะเปิดในเบราว์เซอร์โดยอัตโนมัติ

การเปิดผ่าน local server จำเป็นสำหรับ JavaScript modules และการใช้งานกล้อง

## การควบคุม

| การทำงาน | คีย์บอร์ด | กล้อง |
| --- | --- | --- |
| กระโดด | `Space` หรือ `ArrowUp` | เปิดปาก |
| หมอบ | `ArrowDown` | ก้มหน้า |
| กลับเมนู | ปุ่ม `Menu` | - |

เปิดกล้องได้จากหน้า **Settings** หรือปุ่ม **Camera off** บนหน้าจอเกม เบราว์เซอร์จะขอสิทธิ์ใช้กล้องในครั้งแรก

## โครงสร้างโปรเจกต์

```text
.
├── pictures/          # รูปภาพตัวละคร ฉาก และสิ่งกีดขวาง
├── web/
│   ├── index.html     # โครงสร้างหน้าจอเกม
│   ├── styles.css     # รูปแบบหน้าเว็บ
│   └── js/
│       ├── app.js     # เชื่อมต่อส่วนต่าง ๆ ของเกม
│       ├── camera.js  # กล้องและการตรวจจับใบหน้า
│       ├── game.js    # game loop และ collision
│       ├── menu.js    # เมนูและหน้าจอต่าง ๆ
│       └── score.js   # คะแนนและคะแนนสูงสุด
└── README.md
```

## เทคโนโลยี

- HTML5 Canvas
- CSS3
- JavaScript ES modules
- MediaPipe Tasks Vision ผ่าน jsDelivr CDN

## หมายเหตุ

- โหมดกล้องต้องใช้อินเทอร์เน็ตเพื่อโหลด MediaPipe และโมเดลตรวจจับใบหน้า
- หากกล้องหรือโมเดลไม่พร้อมใช้งาน ยังสามารถเล่นด้วยคีย์บอร์ดได้
- คะแนนสูงสุดเก็บไว้ใน `localStorage` ของเบราว์เซอร์
